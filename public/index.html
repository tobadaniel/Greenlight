How it works

SERV Reasoning (OpenServ) extracts a draft's checkable claims and judges them against the brief, then rewrites failing drafts from the evaluator's critique. Reppo's Evaluation API supplies the independent verdict: score, decision, confidence and a ship / review / block route.

Why a gate

A human review pass costs time on every document an agent writes. Greenlight costs cents per evaluation, keeps the audit trail as the compliance record, and stops the one invented promise that turns into a refund fight.

Demo mode

With no API keys configured, the seeded cases run on clearly labelled simulated verdicts so the loop can be explored end to end. Add SERV_API_KEY and REPPO_API_KEY on the server and every verdict on this page is real. Built for the SERV Hackathon Edition 02, Reppo track.
